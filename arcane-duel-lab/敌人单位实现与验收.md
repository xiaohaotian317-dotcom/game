# 敌人交互试炼 enemies1

2026-10-31。正式单机波次关卡按用户要求后置，本轮交付可复用的敌人单位与本地交互试炼。原Sites网站未改动。

## 如何体验

Windows测试包解压整个文件夹，运行 `ArcaneDuelEnemies.exe`；启动进入敌人选择，选英雄、地图和敌人，再点击“与当前敌人交手”。可从原大厅底部的“敌人试炼”进入；原UI与训练入口保留。AD移动、空格双跳、鼠标瞄准普攻、FER技能、Shift冲刺、G机关、P暂停、N重新交手。

源码可在本项目 `npm start` 后访问 `/enemies.html`。`?enemy=B02&hero=lightning&scene=moon&play=1` 可直接测试指定组合。

- 10种小怪、11位BOSS（保留原10位，按新要求增加骷髅王）；另有不占选择阵容的S01纯蜘蛛幼体。
- 22张真正透明的独立动作图集，每张16姿势：6个行走/爬行/飞行帧、待机、前摇、近战、收招、远程、特殊/召唤、受击、失衡、倒下、死亡。按实际alpha落脚点校准，不拆开头和身体。
- 独立生命、受击/失衡、死亡；地面单位追击、借台面追高处、绕开掩体；远程保距并在射线被挡时重新找位置。主角、木灵鹿、普通弹体、技能、控制和场景机关复用实际战斗逻辑。
- 每个BOSS都有自己的近战连招、远程招式与特殊主动；招式包含前摇、有效时间、收招，单次攻击不按渲染帧重复扣血；半血第二阶段适度加快节奏。

## 关卡如何复用

```js
import {spawnEnemy} from './src/enemy-simulation.mjs';
import {loadEnemyAssets} from './src/enemy-painter.mjs';

// world / assets / renderer 由现有游戏创建，不需要另外一套主角模拟。
await loadEnemyAssets(['B02', 'S01'], assets);
world.enemyArt = assets.enemyArt; // 与画师共用喷吐起点/落脚校准
world.targets = [];              // 关卡自行决定是否保留原目标
spawnEnemy(world, 'B02', {x: 1280, y: world.floor});
// 继续使用原step(world, STEP, input)和renderer.draw(world)。
```

`placeEncounter`替换当前敌人组合；`clearEnemies`清理敌人、弹体、领域和相关状态。召唤型首领预载S01或M06依赖。不要把NPC的持续伤害、召唤或控制只放在渲染器里。

模块：enemy-roster定义职责、动作和数值；enemy-simulation管理AI/招式/召唤/状态；enemy-painter管理图集与特效；enemy-lab只负责选择、加载与输入。simulation通过hooks复用伤害、物理、普通弹体和木灵鹿。元数据由scripts/inspect-enemy-atlases.py只读分析PNG生成，不重绘或覆盖源图。
