# 近战雷拳与四职业特效修订 · combat7

日期：2026-10-29。用户本轮要求已接入游戏与角色检视，主观美感、瞬间动作和实战手感保留待用户验收。当前仍是六职业单人动作试炼，未实现正式网络对战。

## 实际变化

| 对象 | 当前行为 |
| --- | --- |
| 雷行者头部 | 新一体头颈主体只小幅抬头，目视前方；保留原身体前倾。按新主体重新校准肩与髋锚点，游戏头像与放大页共用它 |
| 雷行者普攻 | 真正近战雷拳：面前约 100 范围，不发远程弹体、不穿实际墙体；满电荷命中额外放电，挥空不消耗 |
| 雷行者 F | 贯雷突进，移动阶段敌方普通弹体穿过角色；命中才开放折雷二段，结束后恢复正常受击 |
| 雷行者 R | 选中附近敌人时实际推进至其身前再贴身落雷；选空地时推进指定有效台面。保留技能穿上层平台规则 |
| 影刃普攻 | 刀弧、亮刃尖与实际攻击方向统一，左右朝向只镜像一次 |
| 影刃 F | 低位突进留下连续整身鸦影，保存每个影子的姿态、位置和朝向；带羽片与细线，影子逐渐淡出 |
| 霜语者 | 完整冰晶雪冠、六角雪花、寒雾、地面冰纹；冰镜与大招边界跨过图集分区线，恢复原先被截掉的上部 |
| 星术师 | 金紫星轨、轨道光点、空间门、引力收缩线、坍缩多层冲击环与星屑 |

雷电使用白金亮芯、冷色辉光和不断变化的折线分叉，覆盖雷拳、突进牵引、满电荷和落雷；四职业保留起手、释放、命中、消散各阶段。背景继续沿用详细三境和原轻度环境调色。

## 操作与二段

原所有 Q 技能统一改为 **F**，其余 **E / R / Shift** 不变。机关交互改为 **G**，防止与技能冲突。技能栏、提示、二段倒计时、检视页与操作说明已同步；内部模拟槽名 `q` 仅为兼容 ID。

| 角色 | 主要二段 | 窗口 |
| --- | --- | --- |
| 焰术师 | E 焰跃 → 落烬 | 2.5 秒 |
| 森灵 | E 灵鹿召唤 → 角跃令 | 3.5 秒 |
| 霜语者 | F 凝冰阶 → 碎晶 | 3.5 秒 |
| 雷行者 | F 命中 → 折雷 | 3.5 秒 |
| 影刃 | E 影步 → 返影 | 3.5 秒 |
| 星术师 | F 引力井 → 斥星 | 3.5 秒 |

窗口从一段释放/命中开放时计时，一次二段，与原技能共用冷却。火落烬仍需在空中使用；增加窗口不取消职业条件。星引力井寿命同时延长，避免二段窗口仍在但原领域已消失。

## 素材与实现

使用内置 imagegen 以原透明图集为参考编辑生成，保留 PNG 透明通道，未用 Python 绘制或修改图片像素。最终资源位于 `dist/assets/heroes/`：

- `lightning-core-v2.png`：小幅抬头主体，肢体仍用原 rig-v1。
- `frost-fx-v2.png`、`lightning-fx-v2.png`、`shadow-fx-v2.png`、`star-fx-v2.png`：四套透明技能图集。
- [完整提示词与输入图](dist/assets/heroes/refinement-prompts-v2.json)。
- [精确裁切边界](dist/assets/heroes/refinement-bounds-v2.json)。

`scripts/inspect_refinement_assets.py` 只复制原生成图、读取透明度及校准元数据。绘制采用 `roster-painter-v2.mjs` 与 `vfx-geometry.mjs`；旧画师和 v1 图片保留供追溯。影残影最多 10 个，每约 0.027 秒保存姿态，寿命 0.8 秒；雷影寿命 0.42 秒。
