# 雷行者拳端与头颈修复 · combat8

2026-10-29，根据用户三张实机截图修复。原问题：雷拳电光沿用 `player.y-57` 固定身体点；抬头稿颈部过长，叠加前倾造成伸颈和驼背感。

## 当前行为

- 普攻初始坐标取真正近手拳端。没有武器的雷行者不再加一段虚拟武器尖端偏移。
- 游戏渲染从当前混合姿态、前后帧位置插值、朝向和角色比例得到实际拳端，提供给雷拳画师；电光和亮芯每帧跟随同一个拳端，收拳时仍衔接。整身残影不会覆盖此锚点。
- 主体改用 `dist/assets/heroes/lightning-core-v3.png`：缩短颈部并向肩线内收头，目视前方；躯干、肩/髋的素材坐标系保持。减小过度的站立/出拳前倾，不改成完全站直。
- 头像重新聚焦脸、头发与下巴，减少颈部和胸口露出。角色检视增加雷拳的实际电光，可定格/拖动/切换左右朝向核对。

主体图由内置 imagegen 基于 v2 编辑，透明 PNG 原样复制，没有使用 Python 修改像素。精确提示词与来源为 [lightning-neck-v3-prompt.json](dist/assets/heroes/lightning-neck-v3-prompt.json)，先前主体保留供追溯。
