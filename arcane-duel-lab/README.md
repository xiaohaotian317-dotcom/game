## 操作

| 按键 | 行为 |
| --- | --- |
| A / D 或左右方向键 | 移动 |
| 空格 / W / 上方向键 | 跳跃，再按一次二段跳 |
| S + 空格 | 下穿单向平台 |
| S | 空中加速下落 |
| 鼠标移动 + 按住左键 / J | 瞄准并连续普攻 |
| F / E / R | 职业技能，二段在限时内再次按同一键 |
| Shift | 冲刺，短暂无敌 |
| G | 操作附近地图机关 |
| 1～6 | 切换六位英雄 |
| P / Escape | 暂停或继续 |
| V | 画面定格或继续 |
| N | 重置当前试炼 |

技能栏可点击。训练设置支持木桩移动、反击与 0.5× 慢动作。角色检视 `characters.html` 支持动作播放、定格、进度拖动、左右朝向；`?pose=f&still=1` 可查看 F 施法关键帧。

## 地图与战斗规则

沿用三张详细场景，只对环境轻度收敛色彩：月光遗迹、熔岩祭坛、浮空花园。保持 2304 宽度、双侧回廊、跟随/全景镜头及九类机关。角色与技能不参与环境调色。

普攻不能穿墙，雷行者和影刃近战同样检查墙体；技能按职业穿过障碍。火陨石在正常速度约 1 秒落地，爆燃印、陨石、古树及持续领域按光标下方第一块有效台面落地。原两位左手施法仅自然露出，保持相对躯干静止。

## 运行与验证

本机需要Node.js >=22.13，无第三方运行依赖；生产版本在network-host安装依赖并构建Worker。

```powershell
npm start
npm test
node scripts/audit-scene-routes.mjs
```

预览默认http://127.0.0.1:4173/，可通过PORT改端口，本机服务包含房间API。dist顶层为原生源码，本机无需构建；生产需npm run build。135项检查涵盖既有战斗、全角色通行、双角色和房间/回合协议。

## DUEL11 双人联机

大厅进入duel.html创建或加入房间。加入者先准备，房主开始；六人全开放，双方选完确认后随机三境、倒计时3秒，先赢两局获胜，结算可返回房间。WebRTC直连优先、HTTP转发兜底，显示真实RTT。135项检查与本机双客户端通过，公开部署状态以三份集中记忆最新记录为准。

本地npm start（Node>=22.13）同时提供游戏/API；生产先在network-host安装依赖，再从游戏根npm run build。原生源仍在dist顶层，client/server与network-host/public为生成副本。
