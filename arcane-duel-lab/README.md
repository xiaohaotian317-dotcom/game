## 操作

| 按键 | 行为 |
| --- | --- |
| A / D 或左右方向键 | 移动 |
| 空格 / W / 上方向键 | 跳跃，再按一次二段跳 |
| S + 空格 | 下穿单向平台 |
| S | 空中加速下落 |
| 鼠标移动 + 按住左键 / J | 瞄准并连续普攻 |
| Q / E / R | 职业技能 |
| Shift | 冲刺，短暂无敌 |
| F | 转向月镜，使投射物折射 |
| 1 / 2 / 3 / 4 / 5 / 6 | 切换焰术师 / 森灵 / 霜语者 / 雷行者 / 影刃 / 星术师 |
| P / Escape | 暂停或继续 |
| N | 重置当前试炼 |

技能栏也可以直接点击。失去窗口焦点时会自动暂停，可点击「继续」。

## 两名角色

- **焰术师**：焰矢、爆燃印、焰跃、陨火天坠。E 释放后 1.5 秒内再按 E 接「落烬」下砸，落地留下火焰区。命中附加 3 秒灼烧，再次命中刷新时长，不叠加独立灼烧计时器。爆燃印和陨火可破坏木桥。
- **森灵**：荆棘籽、缚根、灵鹿召唤、古树庇护。E 释放后 2 秒内再按 E 指挥同一只木灵鹿角跃冲撞。木灵鹿命中回复 3 点生命，每 0.8 秒至多触发一次。古树生长出两处可站立枝台，并在树根范围内回复生命。

地图另有单向平台、可修复木桥、反射月镜、弹跳花。右侧可开启移动木桩、反击与半速检视，便于检查技能衔接。

## 运行与验证

需要 Node.js，无第三方运行依赖。

```powershell
node scripts/serve.mjs
node --test tests/simulation.test.mjs
```

默认预览地址由启动命令打印。设置环境变量 `PORT` 可更换端口。`dist/` 可作为静态站点部署。

运行 `node --test tests/*.test.mjs` 执行全部 54 项检查，覆盖角色连接、移动跳跃、二段技能、战斗与召唤物、普攻连续碰撞、指定技能落点与时序、镜头，以及三张扩展地图的实际跳跃路线。`node scripts/audit-scene-routes.mjs` 可重新生成路线报告。

2026-10-29 已重制火焰、陨石、植物和木灵鹿特效；普攻间隔增加 50%，地图宽度增加 60%，支持跟随 / 全景镜头和 V 定格检视。素材与具体参数见 [技能特效与战斗检查](技能特效与战斗检查.md)。

最新版本按用户澄清，让指定位置技能落到鼠标下方的第一个台面；陨石约 1 秒命中并穿过上层平台，普攻继续挡墙。三张场景与平台已重新设计为低对比风格，见 [技能落点与低对比场景](技能落点与低对比场景.md)。

## 本轮范围

这是单人操作的动作与战斗验证场，尚未接入双人联机、完整选角、抽卡经济、关卡进度或账号存档。动画采用部件骨骼方式，仍可继续打磨脚部接地、服装遮挡、施法姿态与打击反馈。

生成素材的原始提示词保存在本地 `art-source/production-prompts.json` 与 `art-source/character-v2-prompts.json`，使用内置 image_gen 工具制作。概念图位于父目录美术资料中；实际发布使用的原始 PNG 均在 `dist/assets/`。
