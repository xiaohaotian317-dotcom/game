## 操作

| 按键 | 行为 |
| --- | --- |
| A / D 或左右方向键 | 移动 |
| 空格 / W / 上方向键 | 跳跃，再按一次二段跳 |
| S + 空格 | 下穿单向平台 |
| S | 空中加速下落 |
| 鼠标移动 + 按住左键 / J | 瞄准并连续普攻 |
| F / E / R | 职业技能，二段在限时内再次按同一键 |
| Shift | 冲刺，短暂无敌 |
| G | 操作附近地图机关 |
| 1～6 | 切换六位英雄 |
| P / Escape | 暂停或继续 |
| V | 画面定格或继续 |
| N | 重置当前试炼 |

技能栏可点击。训练设置支持木桩移动、反击与 0.5× 慢动作。角色检视 `characters.html` 支持动作播放、定格、进度拖动、左右朝向；`?pose=f&still=1` 可查看 F 施法关键帧。

## 地图与战斗规则

沿用三张详细场景，只对环境轻度收敛色彩：月光遗迹、熔岩祭坛、浮空花园。保持 2304 宽度、双侧回廊、跟随/全景镜头及九类机关。角色与技能不参与环境调色。

普攻不能穿墙，雷行者和影刃近战同样检查墙体；技能按职业穿过障碍。火陨石在正常速度约 1 秒落地，爆燃印、陨石、古树及持续领域按光标下方第一块有效台面落地。原两位左手施法仅自然露出，保持相对躯干静止。

## 运行与验证

需要 Node.js，无第三方运行依赖。

```powershell
npm start
npm test
node scripts/audit-scene-routes.mjs
```

预览默认 `http://127.0.0.1:4173/`，可通过 `PORT` 改端口。`dist/` 是直接运行的网站源码，无构建步骤。自动检查 97 项，涵盖连贯动作、碰撞、落点、召唤物、四职业机制、新键位、近战、闪避、残影、特效边界与六人三地图跳跃路线；检查记录见修订说明。
