## 原创与生成方式

- `scores-v1.json` 保留完整和声、段落、每个音符的音高/起拍/时值/力度/声像；分别 151 与 200 个事件。旋律和和声为本次任务独立编写，没有采样、下载、引用或改编现成曲目。
- `compose_music.py` 用 NumPy 与 Python 标准 `wave` 离线合成：多声部轻失谐弦音、带包络的泛音拨弦、钟琴、中音长笛与暗色簧管，另加柔化的立体声房间反射。
- 对 52 Hz 以下及 6.3 kHz 以上作柔和滤波，去除直流偏移，保留音效空间。此处“低音量”是素材混音选择，不代替游戏的独立音量控制。
- 所有音符尾音、房间反射均按文件长度回绕累加，频域滤波同样按周期处理；首帧自带前一循环的尾韵，不添加首尾静音。不需要把尾音另剪掉。

## 接入建议

1. 将两个 WAV 作为完整音乐文件解码为 `AudioBuffer`，设置 `loop = true`，`loopStart = 0`，`loopEnd = 64` 或 `60`。不要依赖计时器反复重播，也不要添加 MP3 编码延迟。
2. 可采用默认音乐音量 35%，允许用户独立开关与调节。整体主音量应同时约束音乐与音效；音乐关闭不应关闭战斗音效。
3. 首次用户点击后再开始播放；页面隐藏/离开时暂停或静音，不要积累多份循环播放器。切换两首歌可用短淡入淡出，文件内部循环不需要交叉淡化。
4. 大厅、图鉴、召唤之间保留当前大厅音乐播放位置，避免每次页面切换从头开始。关卡配乐为克制探索氛围，不强制做首领战的高响度跳变。

已完成乐谱与信号层面的检查；本 Agent 没有做人类听觉主观试听，不能据此声称“用户已试听通过”或“音乐风格已验收”。建议在实际战斗音效叠加后试听，最终音乐喜好与音量仍待用户验收。

## 重现

在已安装 NumPy 的 Python 环境运行 `compose_music.py` 即可重新生成这两首 WAV、完整乐谱、manifest 与 SHA256 清单。脚本只写入自身所在目录；固定乐谱与随机种子，不需要网络或乐器音源。
