# 项目需求

更新：2026-11-04。这里只维护当前有效产品规则；模块与资源见《项目架构》，替代关系、交付证据、授权和未完成事项见第三份文档。未标为用户硬性要求的精确参数均为可调实现默认值，修改时须同步数据与验证，不把默认值冒充用户原话。

## 1. 方向、模式与美术

- 《秘境决斗》是原创暗黑奇幻、手绘风格的横版动作游戏。最初坦克只是短局双人对打的例子，现方向是职业角色、跳跃/下落、连贯技能、被动、衍生操作与地图反馈。希望短局决胜，但未锁定单局时长，参考图01:12不是硬性时间目标。
- 沿用六职业，不扩为八人。保留原网页版和原UI；当前主要交付可离线玩的Windows应用，局域网对战适用同一Wi-Fi/局域网。异地穿透、手机端、正式账号/云存档尚非已完成功能。玩家不需要安装GPT或插件。
- 正常入口：启动主页面→点击开始游戏→大厅→英雄召唤、双人决斗、单机闯关。大厅三张整卡均可点击，去掉原卡片底部三个重复按钮。英雄图鉴旁另有独立妖兽图鉴，分普通妖兽与变异妖兽（BOSS）。保留角色检视、技能图鉴与训练/机关试炼入口。
- 用户强调游玩角色是表现重点，允许动作和特效更复杂，优先保证职业辨识、动作发力/衔接、打击感与美观，再核稳定运行；不以简单占位代替角色表现。
- 全部UI、局内图标、装备/道具/技能图标都要漂亮、符合职业和统一画风，小尺寸清楚，有质感与稀有度框；不能用简单几何占位充当最终稿。悬停/键盘聚焦有实用简介，图标说清用途、数量、职业限制。
- 保留参考图的月夜城堡、废墟、拱桥、旗帜、藤蔓、花草、瀑布等细节。背景稍淡、降低对比/饱和/锐度与刺眼明暗，衬托人物和技能；不再换成被否定的简单空场景。最新要求允许远景不透明度再减10%，仅作用背景，不能把人物、技能、HUD和可踩平台一起弱化。
- 概念图、动作图集、可交互实体、逻辑验证、发布和用户美术/手感验收必须区分；美术生成或自动测试不代表玩家满意。

- 每人有独立待机、移动、起跳/下落/落地、普攻、F/E/R施法、受击和倒地动作，前摇→释放→命中→收招丝滑衔接；职业轮廓、武器与动作对应，不能只是六人同姿势换色。
- 头颈躯干对齐，肩/肘/胯/膝/手/武器锚点稳定，持R时不能手臂乱飞，肩端可小幅错位；抬臂不能有不协调的物件向后甩。避免整体微后仰、断颈、飘头、肢体分离。
- 焰术师、森灵施法时左手稍露、自然静止即可，不加主动托举/挥动。雷行者和影刃头颈适当收回肩线、抬眼前视，保留自然战斗姿态，不驼背、长脖子或僵硬站直。头像与局内造型都要检查。
- 最新游玩重点（T33）：问题是动作设计僵硬而非帧率，不能只增加插值/帧数。六人修正后仰重心，设计职业待机、攻击前摇/发力/收势，二段跳须有明显区别于一段跳的新动作；头部、发梢、斗篷有克制且连贯的随动，肩颈不分离。起跳/顶点/下落/落地与走路/施法自然衔接，保持原跳跃物理/可达性。修改前保留可用基线并提供动画回退方式；主观协调性须用户验收。空中砸落技能的地面范围预警需有职业材质、蓄力/临界时机，清楚且好看。
- 雷行者普攻特效重新制作，明确蓄电/出拳/命中/消散节奏，金白分叉雷弧、短促近战拳爆、有力量，不能变成远程激光或遮住人物；从实际出拳手部发出，不能低到腿部；影刃普攻与面朝/攻击方向一致。影袭有完整身体残影。霜R上半部不可被图集边界截断；后补四职业VFX需同样华丽、有材质、细节和辨识度。

## 3. 公共战斗规则与操作

- A/D移动，空格二段跳，Shift冲刺，S+空格下穿，鼠标瞄准/普攻；外显技能键统一F/E/R，G交互。内部历史槽名`q`不必改名，但不能让UI再显示旧Q技能。单机Q留给御天剑，1/2切角色、C拾取、X结算、V捕捉、P/Esc暂停、F11全屏。训练场旧数字选人只在该模式使用。
- 普攻“慢50%”按已落实口径为发射间隔×1.5，不是弹速减半：焰术师0.42→0.63秒、森灵0.46→0.69秒。要有攻击节奏、音效、命中停顿/反馈，爆炸不是无力的小光点，也不能满屏眩光遮住战斗。
- 普攻遇实体墙/掩体/可挡弹平台停止，包括追踪弹和近战；连续扫掠防高速穿薄墙。技能可以按技能设计穿墙/平台，不把普攻拦截规则套给全部技能。
- 雷行者、影刃普攻范围比旧版+25%（默认100→125、110→137.5）。突进后与敌人身体重叠仍可击中；完全处在身后且不再重叠的敌人不能被前向普攻打中。墙体仍拦截。
- 雷行者为近战，R突至敌方身前近身爆发。F贯雷刺有效突进期间可躲普通敌弹，结束后恢复受击；不能删掉经过的子弹或令整段收招无敌。命中才开放折雷衍生。
- 有衍生的技能适当延长窗口：当前火焰2.5秒，其他职业3.5秒；同键衍生一次、共用冷却、不重复扣蓝。传送返回不重置已损生命/资源/冷却，不可反复刷伤害。
- 指定地面技能按鼠标x，从鼠标位置垂直向下寻找第一块可站立支撑：点二/三层间落二层，点一/二层间落一层；不是最近面、上方平台或固定最高层。破桥/缺口继续向下找；支撑移动时跟随锚点，支撑消失应正确清除。古树不能长空中，火球地爆也在有效台面。
- 焰术师R点击后约1秒落到指定支撑，不被上层平台截住；真岩石/熔岩核心、尾焰、落地冲击、碎片、声效和伤害衔接。单机后续坠落速度+20%，正常约0.86秒是当前实现默认值，不再恢复慢悠悠坠落。
- 焰术师E已换成朝指定方向快速投出火球，离屏前再按E在火球当前位置引爆，不原地跳。默认弹速900、接触16/引爆36伤害、半径125、冷却5.5秒；离屏/消失关闭衍生。它是技能，可穿地形。
- 森灵E是有独立血量、会寻找敌人、转向/追击/跳跃/攻击的木灵鹿，有角跃令，不是只向前跑的狐狸或像老鼠的小点；与背包捕获灵宠是不同实体。
- 霜语者F为低伤减速霜环，不生成平台。现公共基础伤害18、衍生12，35%减速2.5秒，寒潮续2秒，3.5秒内可衍生；不要恢复旧10+6低伤版本。
- 六职业基础生命按原版+50%并取整：火180、森180、霜165、雷180、影165、星173。单机再按成长算，不重复乘1.5；UI数值按合理整数展示。

## 4. 双人决斗与三境地图

- 创建房间（可指定房号）→好友输入房号加入；局域网另需房主地址。访客点准备，未准备房主点开始提示“玩家还未准备”。再进入双方英雄选择，六职业全部可用，不受单机拥有状态限制，双方确认准备后进战场。
- 对局随机一张地图，默认整场沿用；每回合开局3秒倒计时，倒计时中不能行动。死亡后双方回出生点并复位回合状态，再倒计时。**先到3分获胜**；比分/血条在局内，胜方胜利、败方失败，均可返回房间。平局不计分重开、断线暂停/超时等为实现默认，后续可平衡。

- 点进入关卡后，独立选角页面有两个空位，选1～2个已拥有英雄，不自动解锁或强塞第二人。出战前保留查看档案/装备的入口。进入后1/2切换，最多两位轮换而不是同时出场。
