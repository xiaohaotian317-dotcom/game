## 2. 技术栈与运行方式

- 原生HTML/CSS/JavaScript .mjs，Canvas 2D绘制游戏，DOM绘制HUD和界面；本机无需构建，生产联机版本需构建Sites Worker壳。
- `scripts/serve.mjs`用Node内置HTTP服务dist与/api/duel，默认127.0.0.1:4173，可由PORT改端口。本机需Node>=22.13，数据库保存在忽略的.local-data/。真实房间入口duel.html，角色检视characters.html。
- `package.json`：`npm start` 启动预览；`npm test` 等同 `node --test tests/*.test.mjs`。
- `node scripts/audit-scene-routes.mjs` 生成六角色、三地图通行报告到 `validation/scene-route-audit.json`。
- 本机 Node/Python 不在 PATH 时，可使用已安装运行时：`C:/Users/xiaohaotian/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe` 与同级 `python/python.exe`。这是本机路径，移机需重新发现。
- Python 辅助脚本使用 Pillow 读取透明度和边界；图片生成源文件另存，脚本不承担人物或场景的像素重绘。
- 当前线上试玩：<https://arcane-duel-motion-lab-1028-a5324e.xiaohaotian317.chatgpt.site/>，DUEL11已部署并公开；/duel为真实房间入口。当前为原生Canvas游戏+Sites Worker/D1房间服务+WebRTC直连/HTTP兜底，135项检查及公网基础验证通过。部署与限制见下方公开发布记录。
- 生产构建：先在network-host/安装依赖，再在游戏根npm run build。scripts/build-online.mjs保留dist顶层原生源，生成dist/client、dist/server及Worker元数据，生成副本不提交。

## 4. 状态与帧处理

`createWorld(hero, scene)` 创建世界，再应用场景和职业初态。主要对象：

- `player`：位置/前帧、速度、朝向、站立平台、跳跃次数/缓冲、施法、二段窗口、冷却、生命、护盾/电荷/星印、相位突进等。
- `platforms`、`obstacles`：有效台面与实体掩体；可破坏/生长/移动支撑有动态状态。
- `targets`：当前训练木桩及其移动、承伤、灼烧、束缚/减速、死亡重生、反击。
- `projectiles`、`effects`、`texts`、`events`：真实弹体、带时序的表现、飘字、供界面/声音消费的事件。
- `fox`：**历史内部字段名，当前实际对象是木灵鹿**。还有 `trees`、`fields`、`constructs`、`iceMirrors`、`portals`、`ghosts`、`roleState` 和 `mechanisms`。
- `time`/`fxTime`、命中停顿、统计、镜头、光标瞄准位置。

app 用 `requestAnimationFrame` 驱动，逻辑固定步长 `1/120` 秒，渲染对前后位置插值。开始/恢复时将实际帧间隔限制在有效区间，姿势混合遇零/负间隔保留原姿态，避免曾出现的非有限坐标、角色异常放大与施法停帧。

技能有一段前摇和明确释放时刻；二段共享原冷却，只消费一次窗口。命中停顿期间保留跳跃、冲刺、技能输入。护盾、追踪弹、持续领域等应修改真实状态，不能只画特效。

## 5. 碰撞、落点与镜头约定

- 正式三境高 680、宽 2304；保留中央 1440 构图并向两侧各扩 432。训练场基础常量为 1440×800，不能混用三境地面高度。
- 三境当前 `characterScale=.82`、`jumpScale=1.14`。基础重力、跳跃等由 simulation 控制，具体数值是实现参数。
- 普攻按上帧到本帧线段扫掠，选择最近接触；先碰实体就停止，不可跨薄墙击中后方目标。装饰只绘制，不自动获得实体碰撞。
- 地面技能按光标下方第一块有效台面锁点，移动台面用平台 ID + 横向偏移跟随。古树/需要支撑的领域另检查原支撑是否存在，避免无故悬空或跳到别层。
- 火 R 为 .18 秒前摇 + .82 秒坠落 = 正常速度约 1 秒命中。保留穿越上层平台的能力。
- 镜头跟随视口宽 1440，全景显示全部 2304；鼠标坐标经过 `worldPoint` 转换，不能直接用屏幕像素做技能落点。
- 地图改动同步改绘制与碰撞，并重新运行全角色路线审计；不要只调整画面而留下不可达的台阶。
