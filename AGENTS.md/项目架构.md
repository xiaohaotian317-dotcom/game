`dist/client/`、`dist/server/`、`network-host/public/`、`.build`等是生成副本；`.local-data/`为本地数据库。源码与生成物不能混淆，不把凭据/SQLite/浏览器存档/缓存上传。

协作执行：主Agent统一开发/接入；素材子Agent按任务仅写`美术概念/协作交付/<任务ID>/<Agent名>/`，目录随实际任务建立。它是待审素材交付区，不是运行时资源或第四份项目记忆；正式资产/meta/引用由主Agent检查后接入。Agent上下文独立但工作区共享，写入归属、监督与验收规则集中见第三份文档“主Agent统筹的并行协作”。

页面：`dist/index.html`启动/训练；`lobby.html`大厅/英雄图鉴；`summon.html?hero=<ID>`独立英雄卡池；`characters.html`动作检视；`skills.html`技能图鉴；`duel.html`房间/对局；`campaign.html`世界图/选队/单机关卡；`bestiary.html`妖兽图鉴；`enemies.html`交互试炼；`desktop.html`离线/LAN连接。服务支持`/lobby`、`/duel`、`/summon`等无后缀别名。

技术：原生ES Modules + HTML/CSS + Canvas2D战场 + DOM交互UI + WebAudio；Node服务/SQLite，Sites用Worker/D1，Windows用Electron。根项目要求Node≥22.13；独立部署示例Node24；桌面当前Electron45.2.1、@electron/packager20.3.0。

- `FrameClock`固定1/120秒，累积上限0.25秒/30步；处理低/负帧间隔、暂停与hitstop输入缓冲，渲染插值。不能再用过短单帧clamp导致低帧走路慢；禁止非有限Canvas坐标。
- 人物渲染、武器/拳头socket和攻击FX使用同一插值姿态/坐标系。屏幕鼠标先经camera逆变换成世界坐标，再算落点；UI缩放/DPR不改伤害范围。
- 普攻扫掠实体碰撞；技能按自身策略穿透。雷行者大招的预览/实际位置共用lightningLandingTarget；地面造物跟support锚点；移动/摧毁支撑及时刷新，不画在悬空旧点。对手在身后和身体重叠的判定不同。
- 单机成长钩子只由campaign开启；训练/PvP不读单机装备、等级、法器/宠物或额外伤害倍率。对局权威与客户端显示分离。
- 背景低对比缓存仅背景层，战斗角色/实体/技能/HUD独立清楚。当前PvP远景默认`saturate(.76) contrast(.84) brightness(.98)`、alpha0.9；单机关卡缓存默认`.73/.82/.92`、DPR上限1.5，避免每帧滤整张大图。

## 4. 联机、HTTP与托管

- `duel-app.mjs`页面/房间状态，`duel-net.mjs`信令与传输，`duel-worker.mjs / duel-simulation.mjs`房主独立Worker权威模拟；`server/rooms.mjs`房间协议共用本地SQLite和Sites D1。`match-rules.mjs`避免前后端比分/血量不一致。
- 优先WebRTC直连：运动包无序/不重传、不排队积压，重要操作可靠并有seq去重。权威120Hz、快照20Hz、输入30Hz，本地预测/输入重放/误差修正、远端插值，镜头维持本地跟随；失败有HTTP/D1兜底。房主权威并非专服反作弊。
- 低延迟策略不等于异地延迟承诺；本机两页面/HTTP94请求、公共信令成功均不能代替两台真实设备弱网、NAT/长局验证。
- `scripts/serve.mjs`是薄启动，`server/http-server.mjs`默认127.0.0.1:4173，站点与`/api/duel`同源，`/healthz`健康。支持`HOST/PORT/DUEL_DB_PATH/PUBLIC_ORIGIN`；HTTPS反代按显式PUBLIC_ORIGIN校验，不能信任任意转发头或把浏览器https来源误比内部http。
- `scripts/build-online.mjs`构建生成client/server副本，保留原dist顶层。`network-host/`为正式Sites Vinext Worker+D1包装和Drizzle迁移，项目绑定见`.openai/hosting.json`；不把认证凭据写文档。Sites归档指定network-host PROJECT_DIR，避免把原dist与副本重复塞包。
- `deploy/standalone/`有Node24/Caddy2 Docker示例、SQLite持久卷；`scripts/package-standalone.py`导出独立运行源码/素材/SQL/配置并排除凭据/数据库/生成副本，不能当Sites发布归档。独立包曾解压启动、双协议客户端3:0验证；Docker/证书/公网未验证，用户没有服务器或托管账号。
- 现有Sites网站保留不被桌面变化覆盖。公开访问拦截/实际版本状态见第三份文档；没有chatgpt.site的WAF控制能力，不能通过改游戏或重部署冒充解除域名拦截。

## 5. Windows离线/LAN客户端与打包

- `desktop/main.mjs / preload.cjs / lan-runtime.mjs`承载原UI、离线本地素材服务、房间服务和连接页。contextIsolation=true、nodeIntegration=false、sandbox=true；IPC校验允许本地origin，限制外部导航/window.open。终端用户无需安装Node。
- 默认稳定本机端口：基础44173、敌人试炼44175、征途44177；QA绑定127.0.0.1随机端口。LAN房主显式对局时绑定0.0.0.0、好友填地址+房号，不能默认将所有本地调试服务暴露公网。
